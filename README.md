# Rename the Planet

make.fun bounty entry. One funny new name for a planet in our solar system, plus the why, in a single line.

Entry: "Saturn is now The Influencer: a ring light it never turns off, a hundred moons in the comments, and it still thinks the spotlight is about the planet."

`main.ts` writes the line to `/output/entry.txt` (Node 22, stdlib only).
